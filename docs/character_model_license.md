# はむ子VRMモデル利用規約

この文書は、Avatar Gatewayに動作サンプルとして同梱する`assets/vrm/はむ子.vrm`の利用条件を定めます。Avatar Gateway本体のMIT Licenseおよび同梱VRMA・背景画像のCC0は、このモデルには適用されません。

「はむ子」は同梱モデルを識別するための名称です。このモデルには特定の人格、性格、口調、経歴または世界観を設定していません。利用者は、この規約の範囲内で任意の名称や人格を設定してアバターとして利用できます。

## 権利

はむ子のキャラクターデザインおよびVRMモデルに関して、法令上認められる権利はモデル制作者に帰属します。モデルはVRoid Studioの標準パーツを使用して制作されています。

## 許可する利用

- Avatar Gatewayで、利用者が設定した名称・人格・キャラクターのアバターとして使用すること
- モデルを使用した会話・表情・モーションなどの様子を、スクリーンショットや動画として公開すること
- この規約を同梱したまま、未改変のモデルをAvatar Gatewayの配布物またはforkに含めること

## 禁止する利用

- 性的な表現またはコンテンツへ使用すること
- 政治活動、宗教活動、またはそれらへの勧誘・支持・反対を表す用途へ使用すること
- モデル単体を販売、レンタル、または再配布すること
- モデルの制作者、権利者、配布元または第三者との関係について、事実と異なる表示をすること

## 免責事項

このモデルは現状有姿で提供します。モデルの利用によって生じた損害について、制作者およびAvatar Gatewayの開発者は責任を負いません。
